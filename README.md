# CineWave - Movie Finder Dashboard

A modern, colorful, and fully responsive movie search dashboard built with **Tailwind CSS**, **Vanilla JavaScript (ES6+)**, and integrated with the **OMDb API**. 

This project is part of my frontend developer portfolio to demonstrate asynchronous data fetching, dynamic DOM manipulation, and interactive UI/UX design.

## 🌐 Live Demo
👉 **[Click Here to View Live Demo](https://gun-emmer.github.io/movie-finder-app/)**

## ✨ Key Features
- 🔍 **Real-Time Movie Search:** Search thousands of movies instantly using keywords.
- 📱 **Responsive Grid Layout:** Optimized UI for mobile, tablet, and desktop screens with smooth hover effects.
- ⚡ **Asynchronous Data Handling:** Built with `async/await` and robust error/loading state management.
- 🎬 **Interactive Modal Detail:** Clicking any movie card opens a detailed pop-up containing plot summaries, ratings, genres, directors, and actors.
- 🎨 **Modern Aesthetic UI:** Styled using Tailwind CSS utilities, custom scrollbars, and dark-mode gradients.

## 🛠️ Tech Stack
- **HTML5** (Semantic Markup)
- **Tailwind CSS** (Styling & Responsive Design)
- **Vanilla JavaScript (ES6+)** (DOM Manipulation, Fetch API, Async/Await)
- **OMDb API** (External Movie Database)

## 🚀 How to Run Locally
1. Clone this repository or download the source code.
2. Get your free API key from [OMDb API](https://www.omdbapi.com/apikey.aspx).
3. Open `app.js` and replace `'GANTI_DENGAN_API_KEY_MU'` with your actual API key.
4. Open `index.html` in your favorite web browser.
